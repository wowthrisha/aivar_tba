=== security note ===
`aws lambda get-function --function-name ps91-t15` returns the
function's environment variables in PLAINTEXT (DATABASE_URL,
OPENAI_API_KEY) as part of its normal output — this is AWS's default
behavior for env-var-configured Lambdas, not a bug in this repo. That
command was run once during this verification and both secrets were
printed to a terminal/chat transcript as a result. User was notified
immediately and asked to rotate both the OpenAI API key and the Neon
DB password. Production follow-up: move these into AWS Secrets Manager
or SSM Parameter Store (SecureString) rather than plain Lambda env
vars, so `get-function` can't expose them at all.
